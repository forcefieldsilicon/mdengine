MDEngine · ForceField Silicon

User Manual

A native macOS viewer for molecular-dynamics trajectories.

Overview

MDEngine renders the final frame of a molecular-dynamics trajectory as a 3D point-sphere cloud using Metal. It ships with two examples — a Lennard-Jones argon melt and a ReaxFF iron oxidation run (bcc Fe slab meeting O₂ gas), each with the deck that generated it — and opens any XYZ / extended-XYZ file from disk. Multi-frame trajectories open at their final frame, with a timeline for scrubbing and playback. Loaded files are followed live: when a running simulation appends frames to the file, they appear on the timeline automatically (the summary bar shows a green “live” badge) — no re-loading needed.

Inspector analysis

Scale bar (Inspector ▸ View): a length reference drawn in the viewport, snapping to a round Ångström value as you zoom. It is exact at the structure's centre depth; in perspective, nearer and farther atoms deviate slightly (orthographic ⌥⌘P is depth-true everywhere). Toggle it off in the same place.

Z-profile (Inspector ▸ Z-profile): depth analysis of the current frame for deposition/oxidation trajectories. Pick the substrate element (the slab; defaults to the most abundant) and the probe (the deposited species). The surface plane is the mean z of the top 5% of substrate atoms — robust against strays and roughness. The readout gives the plane's z, how many probe atoms have penetrated below it (with min · mean · max depths), how many sit chemisorbed within 2.5 Å above it, how many are still in flight, the mean charge of bound probes (when the file carries charges), and a histogram of probe height relative to the surface (orange bars = penetrated). It updates live while scrubbing, during playback, and as a followed file grows. The same analysis is available to agents as the MCP z_profile tool.

File format

MDEngine reads (multi-frame) XYZ and extended-XYZ:

4000
Atoms. Timestep: 2000 (comment line — ignored)
Ar   12.194  3.031  8.207
Ar   11.402  4.114  9.882
...

One frame = a line with the atom count, a comment line, then one element x y z row per atom; extra columns are ignored. Elements render in CPK-style colours (Al silver, O red, Ar cyan; off-white otherwise).

Simulation engine

The rendering pipeline is live today. Simulations run through the mdengine CLI or the MCP server's detached job runner (submit_lammps keeps the machine awake and records results unattended). A Run menu in the app is the planned next step; the bundled lj_melt.in deck is a ready test input.

Command line

The same engine ships as a terminal tool, mdengine:

CommandDoes
mdengine info file.xyzFrames, atom counts, elements, bounding box
mdengine export file.xyz -o out.xyz --frame lastWrite one frame as plain XYZ
